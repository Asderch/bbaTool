# BBA Ambar Data V4.0

BBA Silifke Yeşilovacık şantiyesi için Flask tabanlı ambar yönetim ve sayım uygulaması.

## Modüller
- Sevkiyat Planları & Dashboard
- Plan Takibi
- Malzeme Ağırlık Hesaplama (TR/RU standartları)
- MB52 vs Sayım Fark Raporu
- Personel & İzin Yönetimi
- Malzeme Kontrol (MM60)
- Mutabakat (Excel - Otis - SAP)
- Analytics Dashboard

## Teknoloji
- Backend: Python Flask + SQLite
- Frontend: HTML/CSS/JS (vanilla)
- Desktop: PyWebView + PyInstaller

## Kullanım
```bash
py app.py
```
